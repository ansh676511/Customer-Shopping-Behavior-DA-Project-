## How to Run

### Prerequisites

- Python 3.x
- Jupyter Notebook
- PostgreSQL
- Power BI Desktop

### Step 1: Clone the repository

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

### Step 2: Install Python dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary jupyter
```

### Step 3: Load and explore the dataset

Open the Jupyter Notebook and run the cells to load the dataset and perform EDA.

### Step 4: Set up PostgreSQL

- Create a PostgreSQL database.
- Import the dataset into the database.
- Update the database connection settings.
- Run the SQL scripts to reproduce the analysis.

**Note:** Keep database credentials private. Use environment variables or a local configuration file instead of committing passwords to GitHub.

### Step 5: Open the Power BI dashboard

Open the `.pbix` file in Power BI Desktop. If required, update the data source settings and refresh the dataset.

### Step 6: Review the reports and presentation

Open the analytical report and Gamma presentation to review the final findings and recommendations.
